[01] HTML ELEMENTS

HTML defines the structure of a webpage.

ELEMENT DESCRIPTION
<h1> Main heading of a webpage
<p> Defines a paragraph
<a> Creates a hyperlink
<img> Displays an image
<div> Groups elements together
<ul> Creates an unordered list
<li> Defines a list item
<section> Groups related page content

[02] HTML ATTRIBUTES

Attributes provide additional information about elements.

ATTRIBUTE DESCRIPTION
href Specifies a hyperlink destination
src Specifies an image or resource location
alt Provides alternative text for images
class Assigns a reusable class name
id Assigns a unique element identifier

[03] CSS SELECTORS

Selectors identify which HTML elements to style.

SELECTOR DESCRIPTION
p Selects all paragraph elements
.card Selects elements with class="card"
#header Selects the element with id="header"
* Selects all elements
a:hover Styles links when hovered over

[04] CSS PROPERTIES

CSS controls the appearance and layout of a webpage.

PROPERTY DESCRIPTION
color Changes text colour
background-color Changes background colour
font-size Controls text size
font-family Sets the typeface
margin Controls space outside an element
padding Controls space inside an element
border Adds a border around an element
display Controls how an element is displayed
position Controls how an element is positioned
